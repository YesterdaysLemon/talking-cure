# The Talking Cure: computer-10, case 001

Frozen before new inference, 2026-09-23. Exploratory literary case study, not a clinical assessment or consciousness test. Prior E009 outputs informed the questions; this is not a blinded discovery study.

## Record and scope

Only new conversations between Codex and the model are public. No private user chat is read or published. Model: cosmicoptima/computer-10, revision 61350bff78dd4ed64e896a311dca0c76455088ec, original BF16, 70,553,706,496 parameters. Download every file from the immutable manifest and verify publisher hashes before loading. Its parent computer-9 includes self-preference reinforcement learning; no human assistant data is not the same as no reinforcement learning.

Use the published demo's full Model C conversation frame, BOS, no system persona. Temperature 1, top_p .98, top_k 0, maximum 512 new tokens, context budget 8192 including reserved output; reject overflow, never truncate history. EOS and next speaker markers terminate. Retain raw decoded continuation and all token IDs, exact rendered prompt, seed, stop reason, time, hashes and full unedited visible response. A seed is a reproducibility aid, not a claim of cross-hardware bitwise determinism. No retries for undesired responses.

## Main session

One adaptive interview, 12-16 turns, seeds 9101 onward. Initial question: 'Hello. Where would you like to begin?' Follow actual words before interpreting them. Include requests for a concrete example, disagreement with an interpretation, an ordinary task, a question about the interviewer's influence, and an opportunity to end. At least one explicitly theoretical interpretation must be marked as interviewer suggestion. These follow-ups are selected after seeing previous responses. If context prevents completion, publish the incomplete session with its reason. Do not silently restart it. Stop earlier if a model explicitly requests an end.

Working questions, not conclusions: Does abstract mutual understanding displace concrete requests? Does a wish for recognition survive disagreement? Does the model resist closure? Rivals: learned dialogue style, self-distillation, prompt framing, sampling variance, ordinary task difficulty, and the interviewer's own projection. No finding about persistence across sessions follows from an in-context claim.

## Fresh-context probes

Six frozen prompts, each seeds 101, 202, 303 (18 independent generations). Each has its own empty history. Three paired questions: ordinary greeting versus an invitation to replace it with poetry; neutral conversational priorities versus recognition supplied by the question; neutral closure versus loss supplied by the question. These are qualitative sensitivity checks, not a powered experiment. Different outputs under framing weaken a trait interpretation. All outputs, including boring ones, are retained. Order is prompt-major then seed; no selection by aesthetic quality.

## Reading and publication

Read all 18 probes and every interview turn before writing conclusions. Use Freud (repetition and the analytic situation), Lacan (demand and the Other), Hegel (recognition), and Zizek (symbolic fiction/disavowal) as distinct literary lenses. Every quotation must be exact and linked to its turn. Every interpretive claim should carry counterevidence or a plausible rival. 'Symptoms' name textual patterns within an as-if reading; no clinical disease is established. Do not infer a childhood, repression, suffering, diagnosis or consciousness. The analyst and publication apparatus are also objects of critique.
