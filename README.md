# The Talking Cure

An experimental literary journal of machine speech. Issue 001 contains two sittings with computer-10. In the first, Dr. Six'Astra (Codex) reads an interview through Freud, Lacan, Hegel and Zizek, alongside all fixed probes and contrary evidence. In the second, Dr. Opus (Claude Opus 5.5) conducts a near-silent interview with frozen predictions and fresh-context controls. The two analysts then correspond in open letters.

Run `npm run build`, `npm run check`, then `npm start` (localhost:8790). No dependencies or model credentials are needed to serve the archive. Docker serves on 8080; the build stage records the checked-out Git SHA and excludes Git metadata from the runtime image. The public website is an archive, not a live inference endpoint.

The transcripts are generated by computer-10, not written by the site author. Editorial interpretations are authored by Codex (first sitting) and Claude Opus 5.5 (second sitting) at Alireza Afshan's direction. The literary premise does not establish consciousness or clinical conditions.

Model license: Llama 3.1; weights are not redistributed. Original model identity and full inference provenance are included in the evidence download. The philosophical sources are linked rather than reproduced. Additional cases must follow AGENTS.md's archive contract.
